## Things I've built

Client work, so names are withheld. Each line is a system I designed and shipped.

- **Rental-ops automation stack.** WordPress site, CRM sync, and n8n workflows for a rental business. Webhook ingestion is idempotent with stale-event protection, MySQL upserts are atomic, and revenue reconciles against the rental software of record.
- **State-aware intake and approval pipeline.** Form intake feeds per-state rules, generates PDF letters, and routes them through review and approval. Access links are HMAC-signed, invitation tokens are hashed, and the negative paths have tests.
- **Pay-first order flows.** Customers pay before work starts, and a preview step gates the expensive processing so nobody pays for output they haven't seen.
- **Agency hosting migration.** Moved sites off shared hosting onto isolated RunCloud/Hostinger VPS boxes with a reusable migration runbook. The deploy scripts refuse a dirty tree, ship only committed files, and end with a smoke check.
- **Internal logistics tools** in C#, ASP.NET MVC, and SQL Server/T-SQL, earlier in my career. Still where my habits around data integrity come from.
